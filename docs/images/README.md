## Capture guidance

Use 16:9 or wide desktop screenshots where possible. Crop browser chrome if it distracts from the evidence, but do not crop out status, target, or evidence labels that establish what is real.

Never include API keys, PATs, OAuth tokens, `.env` contents, private repository information, or browser password-manager UI in screenshots.
